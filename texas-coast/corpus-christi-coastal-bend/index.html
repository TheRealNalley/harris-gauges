Reading these gauges

USGS gauges report gage height: the water surface above each gauge's own zero, not a depth. Where that zero is set at 0 ft on a vertical datum the gage height is also an elevation; each gauge page says which. The NWS flood stages (action, minor, moderate and major) are the National Weather Service's references for each location, shown only where the NWS reads the same scale as USGS. How this site works.
