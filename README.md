# Harris County gauge readings

Static pages reporting water surface elevations from Harris County Flood Warning System
stream gauges, with the history the county's own feed does not keep.

The county publishes these gauges through an interactive map that serves only each sensor's
current value. There is no public record of what a gauge read last Tuesday. A polling pipeline
records every reading as it is published and keeps it; these pages are generated from that
store.

Every number on every page comes from stored readings. Nothing is modelled, forecast,
interpolated or smoothed. The pages report measurements and official NWS alert text, and
give no guidance of any kind.

- Readings: [Harris County Flood Warning System](https://www.harriscountyfws.org/)
- Alerts: [NWS Houston/Galveston](https://www.weather.gov/hgx/)
